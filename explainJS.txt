## 🌈 Game Idea:
You’ll see colored buttons light up in a pattern.  
Your job is to **remember and click** the same pattern.  
Each round, it adds one more color.  
If you click the wrong color: ❌ Game Over!

## 💡 Make the button flash when clicked

```js
function animatePress(currentColor) {
  $("#" + currentColor).addClass("pressed");
  setTimeout(function () {
    $("#" + currentColor).removeClass("pressed");
  }, 100);
}
```
🎆 Add a class that makes it flash, then remove it after 0.1 seconds to give it a "pressed" look.

## 🔊 Play Sound

```js
function playSound(name) {
  var audio = new Audio("sounds/" + name + ".mp3");
  audio.play();
}
```
🎵 Loads the sound file (like `"red.mp3"`) and plays it.

---

## 🔁 Reset the game

```js
function startOver() {
  level = 0;
  gamePattern = [];
  started = false;
}
```
⛔ This resets everything so you can start fresh if you mess up.
